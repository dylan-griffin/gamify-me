# GAMIFY.me

Stop procrastinating with gamification! GAMIFY.me turns your goals into quests made of smaller tasks called bouts.

## Disclaimer

The AI features (AI points rating system and AI bout generation) have been removed from this public repo due to lack of funding and time constraints. This is a demo only.

This was a solo hackathon project by Dylan Griffin, and all assets were made by Dylan Griffin.

## Getting Started

Run `npm i` and `npm run dev` to start a local instance of GAMIFY.me.

### Quests and Bouts

Bouts are small tasks that make up your main goal (a "Quest"). Hugging Face was used to auto-generate bouts for quests, but that feature was removed for this demo.
